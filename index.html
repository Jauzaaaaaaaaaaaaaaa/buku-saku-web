2. Dasar CSS

Lihat file style.css. Di sana ada banyak properti CSS dengan komentar fungsi.

Selector

Contoh: p { color: red; } memilih semua tag p.

Class

Contoh: .container { width: 90%; } memilih elemen dengan class container.

ID

Contoh: #html { scroll-margin-top: 20px; } memilih elemen dengan id html.
